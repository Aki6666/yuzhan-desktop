## 0. 全局（壳层，U1）

- [ ] 侧边栏 216px 纯白底：品牌标「语」深青圆角块 + 白字，品牌名「语栈」+ 副标题「言语理解 · 成语积累」
- [ ] 5 个导航项（成语库/闪卡/自测/进度/生词本）图标+文字：hover 浅灰微交互、当前页深青浅底+深青文字激活态
- [ ] 顶栏 56px：左侧提示文案「快速记录错词，碎片时间复习」浅灰小字；右侧「快速记录」按钮（含 Ctrl K kbd）+ 设置齿轮图标按钮
- [ ] 内容区大留白（28–32px），页面背景浅灰 #F7F7F8、卡片纯白、细分割线
- [ ] 整体 OpenAI 式简洁：无大面积高饱和色，深青仅点缀
- [ ] 细滚动条观感（8px、圆角 thumb）

## 1. 成语列表页（U2，F3/AC-07）

- [ ] 搜索框大号、放大镜图标顶置，输入有防抖（200ms）
- [ ] 结果计数「共 X / Y 条」右对齐
- [ ] 筛选区白卡容器：频次 chips（1–5）+ 首字 chips，选中态深青浅底
- [ ] 词条行：词形+拼音+频次点+感情色彩标签；hover 微交互、激活态；命中关键字/拼音 <mark> 高亮（深青系）
- [ ] 虚拟滚动流畅（600 条仅渲染可视区），滚动条位置正确
- [ ] 空态：自绘图标 + 引导文案（+ 有筛选时「清除筛选」按钮）
- [ ] 加载/错误态（重试按钮）

## 2. 成语详情页（U2，F4/AC-02）

- [ ] 顶部词条区：32px 大字词形 + 拼音 + 感情色彩/语域/误用类型徽标 + 频次点
- [ ] 正文分区卡片、细分割线：释义（多义项分号分隔）/ 出处 / 适用 / 辨析组（默认折叠，点击展开 diff）/ 反义 / 例句（exam 带卷别徽标、made 标注）/ 主题
- [ ] 未收录词条：NEmpty 引导；加载失败：重试按钮

## 3. 闪卡页（U3，F5/AC-05）

- [ ] 页头 + 居中复习流：单卡 3D 翻面动效（正面词形 → 判定后翻面释义+判定徽标）
- [ ] 进度胶囊（如 第 3/10 张）
- [ ] 「认识/不认识」判定按钮精修（对错柔和配色 color-mix）
- [ ] 撤销按钮可用；会话小结卡片（认识 X / 不认识 Y / 本轮共 + 再来一轮/去成语库/去自测）
- [ ] 无待复习卡空态：引导去成语库/自测

## 4. 自测页（U3，F6/AC-06）

- [ ] 三态卡片化：开始前（10 题说明+开始按钮）/ 答题中（进度、题干、4 选项、作答后即时反馈对错+考点展示）/ 结果面板（得分、错题回顾、再来一组）
- [ ] 选项 hover 微交互；对/错柔和配色不刺眼；答案位置随机

## 5. 快速输入弹层（U3，F7/AC-03/04）

- [ ] 命中：卡片展示词条（复习一次/标记掌握/查看详情）；未命中：入生词本提示
- [ ] 底部快捷键提示行（Ctrl K / Esc / 回车）
- [ ] 弹层视觉与主题一致（白卡、圆角、阴影克制）

## 6. 生词本页（U2，F7/AC-04）
